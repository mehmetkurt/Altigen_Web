# Project Brief: Altigen

Altigen is a modern web application built on **Umbraco 17** and **.NET 10**. It serves as a comprehensive Content Management System (CMS) solution, leveraging the latest features of the Umbraco platform.

## Core Objectives
- **Modern Architecture**: Utilize .NET 10 and modern Umbraco features (Block Grid/List, strong typing).
- **Performance**: Prioritize Core Web Vitals (LCP, FCP) and efficient resource loading.
- **Accessibility**: Enforce strict accessibility (a11y) standards across the platform.
- **Maintainability**: Follow a clean architecture with separated concerns (Core, Models, Web).

## Key Features
- **Custom Property Editors**: Tailored editing experiences using LitElement and standard Web Components.
- **Modular Design**: Extensive use of Block List/Grid for flexible page construction.
- **Mobile-First**: Responsive design using SCSS and mobile-first methodologies.
