# Product Context

Altigen is designed to facilitate content management with high flexibility and customization. It solves the problem of rigid CMS structures by adopting Umbraco's Block-based editing paradigms.

## User Experience Goals
- **Editors**: Provide an intuitive, preview-rich backoffice experience. Custom property editors (e.g., Advanced Dropdown, Text Alignment, Unit Selector) streamline content entry.
- **End Users**: Deliver a fast, accessible, and visually coherent browsing experience on any device.

## workflows
- **Content Creation**: Editors use the Umbraco Backoffice to compose pages using predefined Blocks.
- **Styling**: Styles are generated dynamically based on block settings, ensuring design consistency while preserving flexibility.
